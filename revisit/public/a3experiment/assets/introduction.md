# Introduction

Welcome to our study! This study aims to test users' ability to gauge differences in population size on a map using four different visualizations (Choropleth, Spike, Hexbin, and Bubble). You will be asked to input the difference in population between the two "cities" / "states" / "regions" within a "country". Each population value is a multiple of 5, and legends / scales have been provided for each individual map. Input a value of 0 if you believe that both labelled points have the same population size. Overlap of data is expected as city data is often independently mapped and large cities are often close together.

This trial should take 5-10 minutes to complete. Thank you!
